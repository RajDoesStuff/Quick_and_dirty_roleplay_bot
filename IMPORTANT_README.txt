IMPORTANT!!!! if you want to run the bot yourself, you need to make a ".env" file inside projects root directory and add both your discord bot token and guild id!

====== Inside .env file =======
DISCORD_TOKEN=[your token]
GUILD_ID=[guild id of a server you want to run the bot on]
===============================

DO NOT delete or edit .gitignore file when committing, if you do so, you can potentially leak your discord bot token!
